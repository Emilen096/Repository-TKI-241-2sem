29. Решить задачу 28, используя функцию-член erase в цикле по обратному итератору. Указание. Организуйте цикл с параметром r – обратным итератором для перебора элементов первой половины исходного дека в обратном порядке (параметр r должен увеличиваться в заголовке цикла). После удаления элемента функцией-членом erase (с параметром --r.base()) следует обязательно использовать возвращаемое значение функции erase для обновления значения итератора r. Поскольку функция erase возвращает обычный итератор, необходимо выполнить явное приведение этого итератора к типу deque::reverse_iterator (в качестве имени типа можно указать decltype(r)).
